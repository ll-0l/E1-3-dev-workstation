# Mini NPU Simulator 초보자 가이드

이 문서는 프로젝트를 처음 접한 사람이 **실행 방법 → 계산 원리 → 결과 해석** 순서로 이해할 수 있게 정리한 안내서예요. 구현 근거와 평가 항목은 [README](../README.md)와 [동료평가 대응표](PEER_REVIEW.md)에 그대로 보존되어 있어요.

## 1. 무엇을 만드는 프로그램인가요?

숫자로 표현된 그림이 십자가(`Cross`)에 가까운지 X에 가까운지 판정하는 프로그램이에요.

프로그램에는 다음 세 가지가 들어가요.

- **패턴**: 판정할 숫자 그림
- **필터**: 비교 기준이 되는 십자가 또는 X 모양
- **MAC 점수**: 패턴과 필터가 같은 위치에서 얼마나 많이 겹치는지 나타내는 값

십자가 패턴을 두 필터에 겹치면 다음처럼 계산돼요.

```text
십자가 패턴 × 십자가 필터 = 5점
십자가 패턴 × X 필터      = 1점
→ 십자가 필터의 점수가 더 높으므로 Cross로 판정
```

점수는 절대적인 합격선이 아니에요. 같은 패턴에 대해 **Cross 점수와 X 점수를 비교해 더 높은 쪽**을 선택해요.

## 2. 먼저 실행해 보기

Python 3.8 이상만 있으면 되고, 별도 라이브러리는 필요하지 않아요.

```bash
python3 main.py
```

메뉴가 나오면 처음에는 아래 두 모드만 확인해도 충분해요.

| 선택 | 기능 | 처음 볼 때 확인할 것 |
|---:|---|---|
| 1 | 3×3 필터와 패턴을 직접 입력 | 입력 → 점수 → 판정의 전체 흐름 |
| 2 | `data.json`의 여러 패턴을 자동 분석 | PASS/FAIL, 성능표, 결과 요약 |

모드 3~5는 패턴 생성, 저장 방식 비교, 1000×1000 대규모 실험을 위한 보너스 기능이에요.

### 모드 1 입력 예시

메뉴에서 `1`을 고르고 아래 행렬을 한 줄씩 입력하세요.

```text
필터 A (십자가)       필터 B (X)          패턴 (X)
0 1 0                 1 0 1                1 0 1
1 1 1                 0 1 0                0 1 0
0 1 0                 1 0 1                1 0 1
```

결과는 `A 점수: 1.0`, `B 점수: 5.0`, `판정: B`가 돼요. 전체 입력 화면은 [실행 로그 1장](RUN_LOG.md#1-모드-1--예시-입력-cross-필터--x-필터--x-패턴)에서 볼 수 있어요.

## 3. MAC은 어떻게 계산하나요?

MAC은 **곱하고(Multiply), 누적해서 더한다(Accumulate)** 는 뜻이에요.

```python
total = 0.0
for i in range(n):
    for j in range(n):
        total += pattern[i][j] * filter[i][j]
```

N×N 행렬에는 칸이 N²개 있으므로 이 계산도 N²번 반복돼요. 그래서 시간 복잡도는 **O(N²)** 이고, 한 변의 길이가 2배가 되면 계산량은 약 4배가 돼요.

## 4. 판정 결과는 어떻게 읽나요?

| 결과 | 뜻 |
|---|---|
| `Cross` | Cross 필터 점수가 더 높음 |
| `X` | X 필터 점수가 더 높음 |
| `UNDECIDED` | 두 점수가 사실상 같아 판정할 수 없음 |
| `PASS` | 판정과 `data.json`의 정답이 같음 |
| `FAIL` | 판정과 정답이 다르거나, 동점 또는 데이터 오류가 있음 |

컴퓨터는 `0.1` 같은 일부 소수를 정확히 저장하지 못해요. 예를 들어 수학적으로 같은 점수도 `0.9`와 `0.8999999999999999`로 계산될 수 있어요. 이 프로그램은 두 점수의 차이가 `1e-9`보다 작으면 동점으로 보고 `UNDECIDED`를 출력해요.

`data.json` 실행에서 6개 중 3개가 FAIL인 것은 프로그램 오류가 아니에요. 세 케이스 모두 정확히 계산하면 두 필터 점수가 같은 **의도된 동점 데이터**예요. 프로그램은 억지로 정답을 고르지 않고 동점 규칙에 따라 정직하게 FAIL로 집계해요.

## 5. 데이터는 어떻게 처리하나요?

모드 2의 처리 흐름은 다음과 같아요.

```text
data.json 읽기
  → 필터와 패턴의 크기·숫자 검사
  → +, cross, x 표기를 Cross와 X로 통일
  → Cross/X MAC 점수 계산
  → 판정과 정답 비교
  → PASS/FAIL 및 성능 요약 출력
```

잘못된 데이터 하나 때문에 전체 프로그램이 멈추지 않아요. 문제가 있는 케이스만 `스키마`, `동점`, `판정 불일치` 중 하나로 분류하고 다음 케이스를 계속 처리해요.
