# 실행 로그 (RUN_LOG)

README에 나온 숫자와 결과는 모두 아래 실행에서 나왔어요.

- 환경: macOS, Python 3.16. 측정 시간은 컴퓨터와 실행할 때마다 조금씩 달라요.
- 입력한 줄도 화면에 보이도록, 입력값을 함께 찍어 주는 실행기로 `main.main()`을 돌려서 캡처했어요. `선택: 1`처럼 프롬프트 뒤에 붙은 값과 행렬 줄이 사용자가 입력한 값이에요.
